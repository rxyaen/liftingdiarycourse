# UI Coding Standards

These rules apply to all UI code throughout this project.

## Components: shadcn/ui ONLY

- **ONLY shadcn/ui components may be used for the UI in this project.**
- **ABSOLUTELY NO custom components may be created.** Do not write bespoke components, wrappers, or composites of your own — build every screen by composing shadcn/ui components directly.
- If a UI need arises, find the matching shadcn/ui component and use it. If it is not yet installed, add it with the CLI:

  ```bash
  npx shadcn@latest add <component>
  ```

- Installed shadcn/ui components live in `src/components/ui/`. They are generated by the CLI and are the only components permitted in the project.
- Layout and styling are done with Tailwind CSS utility classes applied to shadcn/ui components and plain HTML elements within pages — not by creating new components.

## Date Formatting

- All date formatting MUST be done with [date-fns](https://date-fns.org/). Do not use `toLocaleDateString`, `Intl.DateTimeFormat`, Moment, Day.js, or manual string building.
- Dates are displayed as: day of month with ordinal suffix, abbreviated month, full year.
- Use the format string `do MMM yyyy`:

  ```ts
  import { format } from "date-fns";

  format(new Date(2025, 8, 1), "do MMM yyyy"); // 1st Sep 2025
  ```

### Examples

| Date             | Output       |
| ---------------- | ------------ |
| 1 September 2025 | `1st Sep 2025` |
| 2 August 2025    | `2nd Aug 2025` |
| 3 January 2026   | `3rd Jan 2026` |
| 4 June 2024      | `4th Jun 2024` |
